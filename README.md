# PM - Project Management System

A comprehensive project management repository for tracking tasks, planning sprints, and managing projects effectively.

## 📋 Overview

This repository serves as a centralized system for:
- **Task Planning**: Generate and plan tasks using ChatGPT
- **Task Management**: Update and track tasks using Cursor
- **Task Assignment**: Review and assign tasks through Asana
- **Project Planning**: Plan projects with structured templates
- **Sprint Management**: Organize work in sprints
- **Documentation**: Keep track of meetings and decisions
- **Roadmap Planning**: Define long-term goals and milestones

## 🔄 Workflow

This project uses a three-tool workflow:

1. **ChatGPT** → Planning and generating tasks
2. **Cursor** → Updating, tracking, and managing tasks
3. **Asana** → Reviewing and assigning tasks (manual review)

## 🚀 Getting Started

### Task Management Workflow

#### Step 1: Planning Tasks with ChatGPT
Use ChatGPT to:
- Brainstorm project requirements
- Generate task lists and breakdowns
- Define acceptance criteria
- Estimate effort and complexity
- Create detailed task descriptions

**Tips for ChatGPT:**
- Be specific about project context
- Ask for task breakdowns in manageable chunks
- Request acceptance criteria for each task
- Get effort estimates (hours/story points)

#### Step 2: Managing Tasks with Cursor
Use Cursor to:
- Update task status in this repository
- Track progress on tasks
- Modify task details as needed
- Update documentation
- Commit changes to task files

**Using Cursor:**
- Edit task files in `/docs/tasks/` directory
- Update sprint plans and project documentation
- Track time spent and progress
- Keep task status current

#### Step 3: Review and Assignment in Asana
Manually review and assign tasks:
- Review generated tasks for accuracy and completeness
- Assign tasks to appropriate team members in Asana
- Set priorities and due dates in Asana
- Link Asana tasks to this repository's task files
- Track execution status in Asana

### Creating Task Types

This repository provides templates for:

1. **Tasks**: For regular development work
   - Use the task template in `docs/templates/`
   - Generate initial drafts with ChatGPT
   - Edit and track with Cursor
   - Assign in Asana

2. **Bug Reports**: For tracking bugs and issues
   - Document bugs in `docs/bugs/` directory
   - Track resolution progress with Cursor
   - Manage assignment in Asana

3. **Feature Requests**: For new features and enhancements
   - Plan features with ChatGPT
   - Document in `docs/features/` directory
   - Track implementation with Cursor
   - Assign and prioritize in Asana

### Issue Labels

- `task` - Regular development tasks
- `bug` - Bug reports and fixes
- `enhancement` - New features or improvements
- `documentation` - Documentation updates
- `high-priority` - Urgent items
- `good-first-issue` - Good for newcomers

### Priority Levels

- **Critical**: Must be addressed immediately
- **High**: Important, should be done soon
- **Medium**: Normal priority
- **Low**: Can be done when time permits

### Task Status Workflow

```
[ChatGPT: Generate] → [Cursor: Track & Update] → [Asana: Review & Assign] → [Cursor: Update Status] → [Asana: Complete]
```

**Status Values:**
- `draft` - Generated by ChatGPT, not yet reviewed
- `ready` - Reviewed and ready for assignment
- `assigned` - Assigned in Asana to a team member
- `in-progress` - Actively being worked on
- `in-review` - Work completed, under review
- `done` - Completed and verified

## 📝 Using Templates

### Project Planning

Copy the project plan template to start a new project:
```bash
cp docs/templates/project-plan-template.md docs/project-[name].md
```

Edit the file to include:
- Project objectives and scope
- Timeline and milestones
- Resources and team members
- Risks and mitigation strategies

### Sprint Planning

Use the sprint plan template for each sprint:
```bash
cp docs/templates/sprint-plan-template.md docs/sprint-[number].md
```

Include:
- Sprint goals and backlog
- Team capacity
- Daily standup schedule
- Definition of done

### Meeting Notes

Document meetings using the template:
```bash
cp docs/templates/meeting-notes-template.md docs/meetings/[date]-[topic].md
```

Track:
- Discussion points
- Decisions made
- Action items
- Next steps

## 🔄 Workflow

### Standard Workflow

1. **Planning (ChatGPT)**: Generate tasks and project plans
2. **Documentation (Cursor)**: Create task files in repository
3. **Review (Manual)**: Review generated tasks for quality
4. **Assignment (Asana)**: Assign tasks to team members
5. **Execution (Team)**: Work on assigned tasks
6. **Tracking (Cursor)**: Update status in repository
7. **Completion (Asana)**: Mark complete in Asana
8. **Archive (Cursor)**: Update final status in repository

### Detailed Workflow Example

#### Creating a New Feature
1. **ChatGPT**: "Generate tasks for implementing user authentication feature"
   - ChatGPT provides detailed task breakdown
2. **Cursor**: Create file `docs/features/user-authentication.md`
   - Paste ChatGPT output
   - Add metadata (status: draft, date, etc.)
   - Commit to repository
3. **Manual Review**: Review the feature and its tasks
4. **Asana**: Create project "User Authentication"
   - Create tasks in Asana based on feature breakdown
   - Set priorities and dependencies
   - Assign to team members
   - Add due dates
5. **Cursor**: Update `docs/features/user-authentication.md`
   - Change status to "assigned"
   - Add Asana project link
   - Add assignee information
6. **Team**: Work on tasks
7. **Cursor**: Update progress regularly
   - Update completion percentage
   - Note any blockers
   - Update status to "in-progress" → "in-review" → "done"
8. **Asana**: Mark tasks complete as they finish

### Task Lifecycle

1. **Generate**: ChatGPT creates task details
2. **Document**: Cursor saves to repository (status: draft)
3. **Review**: Manual review for accuracy
4. **Ready**: Cursor updates status to "ready"
5. **Assign**: Create and assign in Asana (status: assigned)
6. **Start**: Begin work (status: in-progress)
7. **Track**: Cursor updates progress and notes
8. **Review**: Work reviewed (status: in-review)
9. **Complete**: Asana marks complete, Cursor updates (status: done)
