# Contributing to PM

Thank you for your interest in contributing! This document provides guidelines for contributing to this project.

## How to Contribute

### Reporting Issues
1. Use the appropriate issue template (Task, Bug, or Feature Request)
2. Provide clear and detailed information
3. Include relevant labels and priority
4. Search existing issues before creating new ones

### Working on Tasks
1. **Choose a task**: Browse open issues and select one to work on
2. **Assign yourself**: Comment on the issue to claim it
3. **Create a branch**: Use descriptive branch names (e.g., `feature/add-login`, `bugfix/fix-auth`)
4. **Make changes**: Follow coding standards and best practices
5. **Test**: Ensure your changes work as expected
6. **Submit PR**: Create a pull request with a clear description

## Issue Labels

- **task**: Regular development tasks
- **bug**: Bug reports and fixes
- **enhancement**: New features or improvements
- **documentation**: Documentation updates
- **high-priority**: Urgent items
- **good-first-issue**: Good for newcomers

## Priority Levels

- **Critical**: Must be addressed immediately
- **High**: Important, should be done soon
- **Medium**: Normal priority
- **Low**: Can be done when time permits

## Status Workflow

1. **To Do**: Task is defined and ready to be picked up
2. **In Progress**: Actively being worked on
3. **In Review**: Code review in progress
4. **Done**: Completed and merged

## Best Practices

### Code Quality
- Write clean, readable code
- Add comments for complex logic
- Follow existing code style
- Keep changes focused and minimal

### Documentation
- Update relevant documentation
- Add inline comments where needed
- Update README if necessary

### Testing
- Test your changes thoroughly
- Include test cases when applicable
- Verify no existing functionality breaks

### Commits
- Write clear commit messages
- Use conventional commit format when possible
- Keep commits atomic and focused

## Communication

- Be respectful and professional
- Ask questions if unclear
- Provide feedback constructively
- Update issue status regularly

## Getting Help

If you need help:
1. Check existing documentation
2. Search closed issues
3. Ask in issue comments
4. Contact maintainers

Thank you for contributing! 🎉
